# 새 모델 계열의 프리셋 표시

카탈로그가 성별 기본형을 하나씩 선언하면 그 기본형의 shape source 규칙을 현재 모델 계열로 사용한다. 이전 계열의 프리셋과 성별·runtime preset이 같은 새 모델이 정확히 하나 있을 때만 이전 템플릿을 기본 목록에서 숨긴다. source 정보가 없거나 대응 모델이 모호하면 숨기지 않는다. 명시적으로 유지해야 하는 이전 ID는 목록에 남긴다.

이는 목록 표시 규칙이다. 과거 ID와 파일, 저장 카드, 커스텀 controls, 작업 기록과 명시적 수동 선택을 새 모델 ID로 바꾸지 않는다. 기존 기본형 이행 규칙은 유지한다. 이 변경만으로 새 기본형이나 source를 선언하지 않는다.

스킨 계약은 이전 22종과 새 20종의 458개 descriptor를 함께 수용할 수 있도록 배열 상한을 256에서 유한한 512로 늘린다. 선택된 모델·UV·스킨·composition의 독립 SHA pin 검사는 유지한다. 인증되지 않은 모델을 booleans만으로 허용하지 않는다.

검증: 타입 검사, 모델 목록·과거 선택 보존·모호한 대응·source 누락·다른 preset, 458개 계약 허용/513개 거절과 선택 파일 SHA 변조 거절 테스트. 실제 모델 pin·기본 ID·S3/ECS 활성화는 최종 모델 QA와 함께 별도 검토한다.
